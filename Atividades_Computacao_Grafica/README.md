1. Preencha o nome do segundo integrante neste README e nos três READMEs das atividades.
2. Confira as capturas em `alunos/capturas/resultado.png`; caso não estejam presentes, execute e use a tecla indicada. O braço deve aparecer dobrado.
3. Crie um repositório no GitHub e envie o conteúdo desta pasta. Preserve `core`, `geometry`, `material`, `images` e demais arquivos auxiliares necessários à execução. Não envie `.venv` ou `__pycache__`.
4. Confira se o repositório está acessível, com os arquivos Python, capturas, respostas e nomes completos.
5. Cada integrante deve entregar no Blackboard o link de seu repositório, conforme as orientações do professor.
